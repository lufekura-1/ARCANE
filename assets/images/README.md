# Sprites do Arcane Hunt

Esta árvore reserva um local previsível para os assets visuais do jogo:

- `characters/`: personagem jogável e NPCs;
- `creatures/`: monstros, summons e bosses;
- `equipment/`: armas, armaduras, munição e itens;
- `effects/`: magias, projéteis e efeitos de combate;
- `tiles/`: pisos, paredes e cenários do mapa;
- `ui/`: ícones e elementos da interface.

Prefira PNG ou WebP com fundo transparente e dimensões consistentes. Os arquivos JavaScript em `../js/` devem concentrar os mapas entre IDs do jogo e caminhos de sprites; não adicione imagens em Base64 ao HTML.
